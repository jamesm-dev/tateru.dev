# Every measurement the rebuild must land on.
#
# FORMAT   key<TAB>value<TAB>why it is this and not another
#
# The checker asserts the VALUE appears in the dashboard's source. That is a presence
# check, not a placement check — it cannot prove 248px was applied to the sidebar. It
# proves the number was not quietly changed to 240, which is the failure that actually
# happens.
#
# SUBSTITUTIONS. A project with its own scale will not contain these literals: Tailwind
# writes w-62, Chakra writes space.4. That is correct and expected. Declare it in
# tokens.map and the checker accepts the declared form instead:
#
#     sidebar.width	w-[248px]
#
# A substitution that is declared can be reviewed. A silent one is how two builds drift
# apart, which is the whole reason this file exists.
#
# COMPOSITE VALUES are not listed. `padding: 32px 32px 48px` is checked as space.6 and
# space.7 being present, because a project that composes it from tokens - which it
# should - never contains the literal triple. Check the parts, not the shorthand.

# --- shell -------------------------------------------------------------------
sidebar.width	248px	Fits the longest nav label plus its count without wrapping, at 14px base
shell.columns	minmax(0, 1fr)	LOAD-BEARING. A plain 1fr grows to fit the board and pushes the last column off screen
prose.width	78ch	Ledes and notes only. The page itself has no max width
font.base	14px	A dashboard is scanned, not read. 16px pushes the fifth column off screen

# --- radii -------------------------------------------------------------------
radius.card	12px	One radius everywhere except controls
radius.input	7px	The base control rule, deliberately tighter than cards
radius.control	8px	Toolbar, search box and drawer controls
radius.field	10px	The create form's larger fields, and the primary buttons
radius.pill	99px	Full round; never a rounded rectangle, which reads as a button
radius.sheet	16px 16px 0 0	The bottom sheet's top corners under 768px

# --- spacing scale -----------------------------------------------------------
space.1	4px	Icon-to-label, pill inner
space.2	8px	Inside a row of controls; column inner padding
space.3	12px	Between cards in a column; heading to its own content
space.4	16px	Card inner padding; gap between board columns
space.5	24px	Between grid cards; sidebar padding; drawer padding
space.6	32px	Between sections; content padding
space.7	48px	Bottom of page; bottom of the drawer

# --- breakpoints -------------------------------------------------------------
break.board	900px	Board columns become one-per-swipe
break.shell	820px	Shell collapses to one column
break.drawer	767px	Drawer becomes a bottom sheet
break.column.width	82vw	A column's width once the board is swiped
