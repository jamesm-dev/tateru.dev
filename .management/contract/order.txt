# Every sequence whose ORDER is part of the design.
#
# FORMAT   key<TAB>a|b|c|d<TAB>maxgap<TAB>why the order is this one
#
# MAXGAP is the largest number of characters allowed between one item and the next.
# Set it for a declaration - an array of columns, a list of statuses - where the items
# genuinely sit together. Leave it empty for a sequence spread across a whole file, such
# as section headings.
#
# It is what makes the check real. Without a gap, a comment above a declaration that
# mentions the same words in the old order satisfies the check, and an array that was
# genuinely reordered goes green. With one, only the declaration can satisfy it.
# An entry with no gap is a smoke test, and should be read as one.
#
# The checker asserts each item appears in the source, and that they appear in this
# relative order. Order is the half of a layout that a rebuild loses first: every item
# is present, one of them has moved, and nothing complains.
